โครงการ AI Travel Charming Chat
แพลตฟอร์มให้บริการ API Key สำหรับ Chatbot (Chatbot-as-a-Service)

================================================================================
1. ภาพรวมโครงการ (Project Overview)
================================================================================
AI Travel Charming Chat เป็นแพลตฟอร์มให้บริการแชทบอทอัจฉริยะในรูปแบบ API-Key-as-a-Service 
(ได้รับแนวคิดการออกแบบระบบสิทธิ์และการคิดเครดิตจาก Slip2Go) ออกแบบมาเพื่อให้เจ้าของเว็บไซต์ 
ธุรกิจท่องเที่ยว โรงแรม และร้านค้า สามารถสมัครบัญชีผู้ใช้ เติมเครดิตข้อความ ตั้งค่าบุคลิกภาพบอท 
(System Prompt) สร้าง API Key และนำวิดเจ็ต Chatbot ไปติดตั้งบนเว็บไซต์ภายนอกได้อย่างสะดวกรวดเร็ว 
ผ่านแท็ก HTML <script> เพียงบรรทัดเดียว

================================================================================
2. กลุ่มเป้าหมาย (Target Audience)
================================================================================
กลุ่มเป้าหมายหลักคือผู้ประกอบการ ธุรกิจท่องเที่ยว โรงแรม ที่พัก และเจ้าของร้านค้าออนไลน์ 
ที่มีเว็บไซต์เป็นของตนเองและต้องการนำระบบผู้ช่วย AI Chatbot มาช่วยตอบคำถามลูกค้า 
ให้ข้อมูลสินค้า บริการ แนะนำสถานที่ท่องเที่ยว และช่วยอำนวยความสะดวกในการสื่อสารตลอด 24 ชั่วโมง 
โดยไม่จำเป็นต้องพัฒนาระบบ AI หรือจัดการโครงสร้างพื้นฐานขึ้นมาเองทั้งหมด

================================================================================
3. ขั้นตอนการใช้งานของผู้ใช้ (User Journey)
================================================================================
1. ผู้ใช้เข้าสู่ Developer Dashboard เพื่อสมัครสมาชิก และเติมเครดิตสำหรับการส่งข้อความ
2. ผู้ใช้สร้าง Bot Profile โดยกำหนดชื่อบอท, System Prompt สำหรับกำหนดคำสั่งและบุคลิกของ AI 
   และระบุรายชื่อโดเมนเว็บไซต์ที่อนุญาตให้ใช้งาน (Domain Whitelist)
3. ระบบสร้าง Public Key ในรูปแบบ pk_live_... ให้ผู้ใช้
4. ผู้ใช้นำโค้ด <script> ไปวางบนเว็บไซต์ของตนเอง
5. เมื่อเปิดเว็บไซต์ จะมีปุ่ม Chat แบบลอย (Floating Launcher) แสดงขึ้นมา 
   และผู้เข้าชมสามารถเปิดหน้าต่างสนทนากับ AI ที่ตั้งค่าไว้ได้ทันที

================================================================================
4. สถาปัตยกรรมและเทคโนโลยี (Architecture & Tech Stack)
================================================================================
- Frontend & Dashboard: Next.js (App Router), TypeScript และ Tailwind CSS
- ฐานข้อมูลและระบบยืนยันตัวตน: PostgreSQL (Supabase) จัดการผ่าน Prisma ORM
- Cache และ Rate Limiting: Redis / Upstash สำหรับตรวจสอบสถานะ Key และติดตาม Rate Limit อย่างรวดเร็ว
- AI Inference Engine: Google Gemini API (โมเดลหลัก: gemini-1.5-flash)
- Embed Widget: Pure Vanilla JavaScript ขนาดเล็ก ไม่มี External Dependency 
  และให้บริการผ่าน CDN / Public Static Assets

================================================================================
5. โครงสร้างฐานข้อมูล (Database Schema)
================================================================================
- users: เก็บข้อมูลการยืนยันตัวตน, อีเมล, รหัสผ่านแฮช (Password Hash), 
  สถานะบัญชี และจำนวนเครดิตคงเหลือ (creditBalance)
- bots: เก็บ UUID, รหัสผู้ใช้งาน (userId), ชื่อบอท, System Prompt, 
  รายการโดเมนที่อนุญาต (allowedDomains), โมเดล AI และวันที่สร้าง
- api_keys: เก็บข้อมูล API Key ที่เชื่อมโยงกับบอทและผู้ใช้ ประกอบด้วย Public Key, 
  Secret Key Hash (SHA-256), สถานะการใช้งาน Key และค่า Rate Limit
- usage_logs: เก็บประวัติการใช้งาน เช่น รหัสบอท, จำนวน Token, โดเมนต้นทาง (originDomain) 
  และเวลาที่ใช้งาน (Timestamp)

================================================================================
6. ลำดับขั้นตอนการทำงานหลัก (System Workflow)
================================================================================
6.1 การสร้างและจัดการ API Key
- เมื่อสร้าง Bot ระบบจะสร้าง Public Key รูปแบบ pk_live_... สำหรับแสดงผล Widget 
  และสามารถสร้าง Secret Key รูปแบบ sk_live_... สำหรับการเชื่อมต่อผ่าน Backend ได้
- Secret Key จะถูกเข้ารหัสแบบ One-way Hash ด้วย SHA-256 ก่อนบันทึกลงฐานข้อมูล 
  โดยจะแสดงค่า Secret Key แบบเต็มให้ผู้ใช้เห็นเพียงครั้งเดียวขณะสร้าง
- Public Key จะเชื่อมโยงกับ allowedDomains เพื่อใช้ตรวจสอบเว็บไซต์ต้นทางที่ได้รับอนุญาต

6.2 การทำงานของ widget.js
- เป็นสคริปต์ Vanilla JavaScript ขนาดเล็ก ไม่มี Dependency ภายนอก
- อ่านค่า data-bot-key จากแท็ก document.currentScript
- สร้างปุ่ม Chat แบบลอยบนหน้าเว็บ และสร้างหน้าต่างสนทนาภายใน Shadow DOM 
  เพื่อป้องกันปัญหา CSS ชนกับสไตล์ของเว็บไซต์เจ้าของ
- บริหาร Session การสนทนาของผู้เข้าชมผ่าน LocalStorage
- ส่งคำถามไปยัง API ผ่าน HTTP POST ที่ /api/v1/widget/chat

6.3 ขั้นตอนการตรวจสอบและประมวลผลที่ Chat Gateway
1. รับข้อมูล publicKey, message และ sessionId
2. อ่านค่า HTTP Header "Origin" หรือ "Referer" จาก Request
3. ค้นหา Public Key ในแคชหรือฐานข้อมูล เพื่อตรวจสอบว่า Key มีอยู่จริงและบอทยังเปิดใช้งานอยู่
4. ตรวจสอบ Origin กับรายการ allowedDomains หากไม่ตรงกัน ระบบจะปฏิเสธด้วยสถานะ 403 Forbidden
5. ตรวจสอบ Rate Limit และเครดิตของเจ้าของบอท:
   - หากยิงคำขอถี่เกินเกณฑ์ ระบบจะตอบกลับด้วยสถานะ 429 Too Many Requests
   - หากเครดิตหมด ระบบจะปฏิเสธด้วยสถานะ 402 Payment Required
6. นำ System Prompt ของบอทมารวมกับคำถามของผู้ใช้ แล้วส่งต่อไปยัง Google Gemini API
7. หักเครดิตของเจ้าของบอทจำนวน 1 เครดิต และบันทึกประวัติการใช้งานลง usage_logs (Database Transaction)
8. ส่งคำตอบจาก AI กลับไปยัง Widget ในรูปแบบ { reply: "..." }

================================================================================
7. ขอบเขตของโครงการ (Project Scope)
================================================================================
1. พัฒนา Next.js Developer Dashboard สำหรับสมัครสมาชิก จัดการเครดิต ตั้งค่า Bot และสร้าง API Key
2. พัฒนา Route /api/v1/widget/chat ทำหน้าที่เป็น Secure Proxy ตรวจสอบโดเมน ยืนยันสิทธิ์ และหักเครดิต
3. พัฒนา widget.js ที่โหลดเร็ว ปลอดภัยด้วย Shadow DOM และแสดงผลได้สมบูรณ์บนทุกหน้าจอ
4. พัฒนาระบบบันทึกสถิติและประวัติการใช้งาน (Usage Analytics)

================================================================================
สรุปโครงการ AI Travel Charming Chat
================================================================================
AI Travel Charming Chat เป็นแพลตฟอร์มให้บริการ Chatbot อัจฉริยะแบบฝังบนเว็บไซต์ภายนอก 
เน้นความสะดวกรวดเร็วในการติดตั้งและการควบคุมความปลอดภัยผ่านระบบ API Key 
ระบบประกอบด้วย Dashboard สำหรับจัดการบอท, ระบบฐานข้อมูลและเครดิต, Secure API Gateway 
สำหรับตรวจสอบโดเมนและสิทธิ์การใช้งาน รวมถึง Widget สำหรับนำ Chatbot ไปแสดงผลบนเว็บไซต์ภายนอก 
โดยทั้งหมดเชื่อมต่อกับ Google Gemini API เพื่อประมวลผลคำตอบที่ชาญฉลาดและตรงตามความต้องการของธุรกิจ
